# X Platform Hashtag Arama Otomasyonu (Selenium + Edge)

Bu proje, **Selenium** kullanarak **Microsoft Edge tarayıcısı** üzerinden **X (eski adıyla Twitter)** platformuna giriş yapmayı ve ardından belirli bir **hashtag** araması gerçekleştirmeyi amaçlar. 
## Özellikler
- Edge tarayıcısıyla otomatik giriş
- Kullanıcıdan alınan hashtag ile arama yapma
- Tarayıcı, kullanıcı Enter tuşuna basana kadar açık kalır
- Basit ve öğrenmeye uygun Python/Selenium yapısı

## Gereksinimler

- Python 3.x
- Microsoft Edge
- Selenium
- WebDriver for Edge (msedgedriver.exe)
